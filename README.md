# Dino do Chrome em Pygame

Versão simplificada inspirada no Dino do Chrome, criada em Python e
Pygame como mostrado no vídeo. Pule os cactos, ganhe pontos e acompanhe
o aumento da velocidade.

## Como executar

Tenha o Python instalado. Na pasta do repositório, execute:

```bash
python -m pip install -r requirements.txt
python dino_do_chrome.py
```

No Windows, se o comando `python` não funcionar, use `py` no lugar dele.

Pressione **espaço** para pular. Ao bater num cacto, a partida reinicia
automaticamente. Feche a janela para sair.

## Código passo a passo

O arquivo `dino_do_chrome.py` contém o jogo completo. A pasta `passos/` mostra as
quatro versões executáveis apresentadas no vídeo: dinossauro, pulo, cactos e colisão com velocidade e pontos.
